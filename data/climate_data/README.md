
# Raw Data Acquisition Declaration

Here we describe where the raw datafiles for this project were sourced.

## Historic and Projected Climate Data

Climate projections were sourced from [this page](https://climate-scenarios.canada.ca/?page=CanDCS6-data) at Environment and Climate Change Canada. On the website, we specified the following parameters:
- **Dataset**: CanDCS-M6
- **Variable**: Mean temp / Min temp / Total precip
- **Model**: Ensemble
- **Ensemble**: Ensemble mean
- **Scenario**: Historical + SSP1-26 / SSP2-45 / SSP5-85
- **Coordinates (NE)**: (`45.5475`, `-78.2464`)
- **Coordinates (SW)**: (`45.5191`, `-78.2869`)
- **Time of Year**: March / April / May
- **Start Year**: 2000
- **End Year**: 2100
- **Temporal Resolution**: Daily output

Historic, daily climate data was provided by Algonquin Park meteorologists.
